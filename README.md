## Description

Thank you for choosing to look at REFSIX Data. If you find any bugs or want some feature not currently included, then my contact information can be found on [my GitHub page](https://github.com/MatthewEmer).

This project is a continuation of my [A-Level Computer Science NEA](https://github.com/MatthewEmer/My-Portfolio/tree/main/Archive/A-Lvl-Computer-Science-NEA), where I created a simple web-scraper, pulling information from the FA FullTime website. 

The next step for that project, and one that I never got to start, was then integrating that data with the data on the REFSIX app. This is an app that allows referees to manage their admin between (and during) games, and to analyse their performance afterwards. This project uses their REST API to collate the data from the app, and produces meaningful insights into trends and recent performances.
